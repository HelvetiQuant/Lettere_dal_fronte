# Note metodologiche

## Fonti dati consultate

- **imi_internati.db > caduti_albooro**: 342.555 record (Albo d'Oro caduti WWI)
- **imi_internati.db > internati**: 20.465 record (IMI — Internati Militari Italiani WWII)
- **imi_internati.db > collegamenti**: entita collegate a record
- **imi_internati.db > record_links**: collegamenti record-to-record (legacy)
- **imi_internati.db > fonti_indice**: fonti archivistiche indicizzate
- **eventi_1gm.db > eventi_1gm**: 49 eventi storici WWI/WII
- **eventi_1gm.db > event_links**: 1.539.685 collegamenti evento-record

## Pipeline utilizzata

1. Query diretta sui DB SQLite locali (nessuna modifica al codice)
2. Match per nominativo (WWI) e cognome+nome (WWII)
3. Cross-reference con event_links, record_links, collegamenti, fonti_indice
4. Formattazione output come da frontend (dossier strutturato)

## Limitazioni

- Ricerca fonti_indice (fonti archivistiche) non ha prodotto match diretti per nome
- record_links per WWII (internati) = 0 (legacy linker non ha processato questa tabella)
- Event links WWII: 26/50 (solo eventi WWI nel DB eventi_1gm, cross-match per luogo/epoca)
- Dati WWII spesso incompleti (data nascita, luogo nascita = — per molti record)
